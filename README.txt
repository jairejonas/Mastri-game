MASTRI — Prototype 1

Open index.html in a modern browser. Best played in landscape orientation.

Controls:
- Left virtual stick: move
- ATTACK: melee nearby target
- SLIP: destabilize nearest enemy (12 energy)
- REDIRECT: temporary projectile-defense field (16 energy)
- LAUNCH: kinetic burst / heavy hit (20 energy)

Mission: stop all three criminals while conserving health and energy.

This is a lightweight gameplay proof-of-concept. It uses abstract geometry rather than the final character artwork so the core controls and systems can be tested first.
